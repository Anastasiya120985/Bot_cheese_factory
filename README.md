# Сырная Фабрика Bot (Bot_cheese_factory)

Телеграм-бот для автоматизации заказов и управления процессами сырной фабрики.

## 📝 Описание

Данный проект представляет собой телеграм-бота, предназначенного для сотрудников и, возможно, клиентов сырной фабрики. Бот помогает автоматизировать процессы учета и управления заказами.

**Основной функционал:**
*   **Для сотрудников:** Учет рабочего времени (отметки о начале и окончании рабочего дня), просмотр и управление заказами.
*   **Для администраторов:** Полный доступ к данным, управление пользователями и заказами.
*   **Система ролей:** Разграничение прав доступа (например, Сотрудник, Бухгалтер, Администратор).

## 🚀 Функциональность

*   **Авторизация и Аутентификация:** Регистрация и вход пользователей в систему.
*   **Учет рабочего времени:**
    *   Фиксация времени прихода на работу (`/start_work`).
    *   Фиксация времени ухода с работы (`/end_work`).
*   **Управление заказами:**
    *   Просмотр списка активных заказов.
    *   Просмотр деталей конкретного заказа.
    *   Обновление статуса заказа (например, "в работе", "выполнен").
*   **Панель администратора:** Управление пользователями, просмотр общей статистики и журналов.
*   **Уведомления:** Отправка уведомлений пользователям о важных событиях.

## 🛠 Технологии

*   **Язык программирования:** Python 3.11+
*   **Фреймворк для бота:** Aiogram 3.x (асинхронный)
*   **База данных:** SQLite 3 (с использованием ORM SQLAlchemy 2.0)
*   **Дополнительные библиотеки:** См. `requirements.txt`

## 📦 Установка и Запуск

### Предварительные требования

1.  Убедитесь, что у вас установлен Python версии 3.11 или выше.
2.  Установите менеджер пакетов `pip`.
3.  Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) и получите API-токен.

### Шаги для установки

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/Anastasiya120985/Bot_cheese_factory.git
    cd Bot_chese_factory
    ```

2.  **Создайте виртуальное окружение (рекомендуется):**
    ```bash
    python -m venv venv
    ```
    *   **Активация на Windows:**
        ```bash
        .\venv\Scripts\activate
        ```
    *   **Активация на macOS/Linux:**
        ```bash
        source venv/bin/activate
        ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Настройте конфигурацию:**
    *   Создайте файл `.env` в корневой директории проекта на основе примера `.env.example`.
    *   Укажите в нем ваш токен бота и другие чувствительные данные:
        ```ini
        BOT_TOKEN=your_telegram_bot_token_here
        ADMIN_ID=your_telegram_user_id_here
        # DATABASE_URL=sqlite+aiosqlite:///database.db (обычно для SQLite указывать не нужно)
        ```

5.  **Инициализация базы данных:**
    *   Запустите скрипт для создания таблиц в базе данных.
    *   Обычно это делается командой:
        ```bash
        python main.py
        ```
        *(При первом запуске, если в коде прописано создание таблиц, база данных будет создана автоматически).*
    *   Или выполните скрипт инициализации отдельно, если он предусмотрен.

6.  **Запустите бота:**
    ```bash
    python main.py
    ```

## 👨‍💻 Использование

После запуска бота, перейдите в Telegram и найдите вашего бота по имени.

**Основные команды:**
*   `/start` - Начать работу с ботом, регистрация/авторизация.
*   `/start_work` - Отметить начало рабочего дня.
*   `/end_work` - Отметить конец рабочего дня.
*   `/orders` - Просмотреть список заказов.
*   `/admin` - Панель администратора (доступно только для админов).
